# PearlCalculator

[**简体中文**](./README_zh.md)

A high-performance Minecraft Ender Pearl trajectory simulator and TNT momentum calculator developed in C++.

## Core Features
- **TNT Calculation**: Automatically solves the required TNT amounts for Red/Blue arrays based on target coordinates.
- **Trajectory Simulation**: Simulate the flight trajectory of a pearl based on the input configuration.
- **Configuration**: Fully compatible with configuration files generated by [PearlCalculatorCore](https://github.com/LegendsOfSky/PearlCalculatorCore). Automatically loads parameters from `config.json` upon startup.

## Roadmap
- **Constraint Calculation**: Support for specifying a target Y-coordinate or flight duration (Ticks) during TNT calculation.
- **Configuration Robustness**: Automatically complete missing fields using default values without overwriting the original file when fields are missing in the configuration.

## Technical Specifications
- **Language**: C++ 17
- **Build System**: CMake 3.10+
- **Dependencies**: `nlohmann/json` (included)
